# 🛡️ AegisPlus — Персональный Dota Plus & Live Overlay

**AegisPlus** — профессиональный софт для анализа статистики и помощи в Dota 2 в реальном времени.

> [!NOTE]
> **100% легально и безопасно для аккаунта Steam**:
> Программа не внедряется в память игры (нет инжектов/хуков) и не модифицирует файлы клиента. Она использует официальный протокол **Valve Game State Integration (GSI)**, разработанный самой компанией Valve. **Риск получения VAC-бана равен нулю.**

---

## ⚡ Ключевые возможности

### 1. ⏱️ Макро-радар и тайминги
* **Пруды Лотосов**: предупреждение за 15 секунд до появления лотосов (каждые 3 минуты: 3:00, 6:00, 9:00...).
* **Руны Мудрости (EXP)**: критическое звуковое и визуальное предупреждение за 30 секунд до руны (7:00, 14:00, 21:00...).
* **Активные руны (Power Runes)**: таймер появления рун на реке на четных минутах (6:00, 8:00, 10:00...).
* **Терзатель (Tormentor)**: предупреждение на 19:00 о спавне Терзателя на 20:00 для сбора команды за Шардом.
* **Тайминг стаков крипов**: оповещение на `:48 - :54` секундах каждого круга минуты («Время бить лесной кемп и уводить крипов!»).
* **Окно Рошана**: отслеживание таймера Аегиса (5 минут) и случайного окна респавна (8–11 минут).

### 2. 📊 Бенчмарки рангов в реальном времени
* Сравнение вашего темпа фарма с реальными средними показателями любого ранга (**Рекрут → Титан**):
  * **Крипстат (LH / DN)**: текущий добив vs целевой показатель с дельтой (`+12 Ahead` или `-8 Behind`).
  * **Нетворс (Net Worth)**: динамическое опережение/отставание по золоту.
  * **Оценка эффективности (Grade S / A / B / C)**: мгновенная оценка вашей текущей формы.

### 3. 🪙 Калькулятор выкупа (Buyback Monitor)
* Расчет точной стоимости выкупа по официальной формуле:  
  $$\text{Стоимость} = 200 + \left\lfloor\frac{\text{Нетворс}}{13}\right\rfloor$$
* Индикатор готовности: зеленое свечение с запасом золота (`+450g резерв`) или красное предупреждение с суммой дефицита (`Не хватает 180g`).

### 4. 💡 Ситуативный советник по предметам
* Анализ состава вражеской команды и автоматический подбор контр-предметов с объяснением:
  * **Black King Bar (BKB)**: при обилии магического прокаста и контроля.
  * **Silver Edge**: против опасных пассивок (Bristleback, Phantom Assassin, Spectre, Huskar).
  * **Spirit Vessel / Shiva's Guard**: снижение бешеного отхила (Morphling, Alchemist, Necrophos, Slark).
  * **Monkey King Bar (MKB)**: против уклонений (PA, Windranger, Butterfly).
  * **Dust of Appearance**: при наличии невидимости (Riki, Clinkz, Nyx, Shadow Blade).

### 5. 🎯 Ассистент драфта (Pick & Ban)
* Анализ пиков команд на стадии выбора героев:
  * Оценка вероятности победы (Advantage %).
  * Топ-5 лучших контрпиков по ролям: Carry (Pos 1), Mid (Pos 2), Offlane (Pos 3), Support (Pos 4/5).
  * Рекомендации банов ключевых угроз для ваших героев.
  * Выявление слабых мест сетапа (нехватка станов, отсутствие танка, избыток физ. урона).

## 🚀 Как запустить

В терминале перейдите в папку проекта и запустите:

```bash
cd ~/projects/dota2-aegis-plus
./start.sh
```

### Доступные режимы:
1. **Основной оверлей (`./start.sh`)**:
   * Запускает прозрачный полноэкранный HUD поверх Dota 2 (Wayland Layer Shell / GTK4).
2. **Веб-версия (`./start_web_only.sh`)**:
   * Запускает только сервер. Интерфейс доступен в браузере по адресу:  
     👉 **`http://127.0.0.1:3000`**  
   * Этот же адрес можно открыть прямо во **внутриигровом оверлее Steam (Shift + Tab)** или на втором мониторе/планшете!

## 🎮 Элементы управления в оверлее

На верхней панели оверлея расположены кнопки:
* **Ранг**: выпадающий список (Herald, Archon, Legend, Ancient, Divine, Immortal) для выбора целевого бенчмарка.
* **Роль**: Pos 1 (Carry), Pos 2 (Mid), Pos 3 (Offlane), Pos 4/5 (Support).
* **🎯 Драфт**: открыть/закрыть модальное окно помощи при пиках и банах.
* **🔊 Звук**: включение / выключение звуковых сигналов и голосовых подсказок.
* **▶ Демо**: тестовый прогон симуляции матча (позволяет протестировать весь интерфейс и тайминги без запуска Dota 2).
* **🔓 Меню / 🔒 Лок (игра)**:
  * В режиме `🔓 Меню` элементы интерактивны (можно нажимать кнопки, менять ранги).
  * В режиме `🔒 Лок` оверлей становится на 100% прозрачным для кликов мыши, чтобы не мешать управлению героем в Dota 2.

## 📁 Структура проекта

```
~/projects/dota2-aegis-plus/
├── backend/
│   ├── analytics_engine.py   # Мозги: расчеты драфта, таймингов, предметов и бенчмарков
│   ├── config_manager.py     # Автоустановка GSI конфига в Steam Dota 2
│   └── gsi_server.py         # HTTP сервер + Server-Sent Events (SSE)
├── data/
│   ├── benchmarks.json       # Кривые CS, NW, GPM, XPM по рангам и ролям
│   ├── heroes.json           # База 125+ героев, контрпиков и синергий
│   └── items.json            # Ситуативные предметы и триггеры
├── frontend/
│   ├── app.js                # Логика HUD, Web Audio звуки, SSE поток
│   ├── index.html            # Разметка оверлея
│   └── style.css             # Glassmorphism стили и анимации
├── overlay_window.py         # Нативное прозрачное окно (GTK4 + WebKit6 + LayerShell)
├── start.sh                  # Основной скрипт запуска оверлея
└── start_web_only.sh         # Запуск только веб-панели
```
